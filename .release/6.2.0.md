# DraCuLa StreamNZB Template 6.2.0

6.2.0 completes DraCuLa's release-automation workflow by adding the manually gated Publish Release path and hardening its candidate validation after the first production dogfood run. It does not change filtering, scoring, trusted-tier policy, adaptive filtering, profile content, Define Library behavior, or formatter behavior. Compatibility remains StreamNZB 6.1.0 / Jhin 0.7.1.

## Release automation

This release adds and hardens the publication half of the release pipeline:

- Adds a manually dispatched Publish Release workflow requiring an explicit version and exact expected `main` commit SHA.
- Runs read-only candidate validation before any privileged GitHub App token is minted.
- Fails closed on stale `main`, tag collisions, already-published releases, malformed release state, duplicate exact-version drafts, incompatible ancestry, or non-green repository checks.
- Creates a direct lightweight tag against the exact validated release SHA and verifies it immediately.
- Deterministically reuses or creates the exact-version GitHub release draft under privileged credentials.
- Uses `.release/<version>.md` as the authoritative public release body instead of trusting Release Drafter content.
- Verifies the published release metadata/body, direct tag, forward compare from the previous stable release, and release-notification workflow.
- Uses conservative partial-failure handling: after tag creation, failures require explicit human recovery rather than automatic tag deletion, movement, recreation, or publication resume.
- Adds bounded retry/poll behavior for transient GitHub visibility and notification states without weakening fail-closed release safety.

The first real Publish Release dogfood run also exposed a self-check deadlock: candidate validation saw the currently running Publish Release job itself as a pending required check. 6.2.0 fixes that by excluding only the exact current Publish Release self-check name while leaving every unrelated pending or failing check fail-closed.
