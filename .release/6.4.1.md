# DraCuLa StreamNZB Template 6.4.1

6.4.1 is a focused correctness patch: it fixes a false-positive in Anime `v0`-`v4` version scoring, closes the reverse direction of a Sword Art Online title-ambiguity gap, and adds subtitle/language diagnostics to DraCuLa Debug. It does not change the compatibility baseline, the production formatter, or the Define Library.

## Anime version scoring fix

The `v0`-`v4` release-version tie-breaker could be fooled by a version-shaped token (`v1`, `v2`, ...) that only appeared inside an ameNZB-style structured `{Tags:...}` metadata block, rather than as a real scene release-version marker — silently awarding or withholding the wrong version-preference points. A `{Tags:...}` block covering the only occurrence of a `vN` token no longer counts; a genuine `vN` marker elsewhere in the release name is unaffected.

## Sword Art Online title-ambiguity guard, reverse direction

A prior release added a guard against a "Sword Art Online" request being satisfied by a "Sword Art Online II" release (StreamNZB's tolerant title-similarity matcher can treat short, non-digit trailing titles as close enough to match). This release closes the reverse direction: a "Sword Art Online II" request no longer admits a bare "Sword Art Online" release through the same tolerant matching. Both guards are independent, exact-title-scoped rules and don't interfere with each other or with any other title.

## DraCuLa Debug subtitle/language diagnostics

The `DraCuLa Debug` formatter variant now shows a new `SUBS` line with:

- raw merged subtitles
- mapped subtitle flags
- languages
- `subbed` state

This is debug-only — the production formatter (`SNZBF1:`) is byte-for-byte unchanged.

## Upgrade impact

- A **profile refresh is required** to receive the Anime version-scoring fix and the Sword Art Online guard.
- A **debug formatter refresh is required only if you use DraCuLa Debug** — the production formatter is unaffected and needs no refresh.
- No Define Library refresh is required — the Define Library is unchanged.
