# DraCuLa StreamNZB Template 6.3.0

6.3.0 reserves a bounded slot for Library-attached releases in the ordinary Best-N ranking cap, so a copy you already have in your library is no longer silently pushed out of the results by unrelated higher-scoring alternatives. Compatibility remains StreamNZB 6.1.0 / Jhin 0.7.1.

## Library Best-N reservation

- Ordinary (non-season-pack) result buckets still retain up to 3 non-Library candidates per resolution + quality.
- One additional Library candidate can now also be retained per resolution + quality.
- Library candidates no longer consume the ordinary Best-3 capacity, so they can't crowd out a non-Library result and can't be crowded out by one either.
- Multiple Library candidates in the same bucket remain bounded to the single highest-ranked one.
- The maximum ordinary bucket size is therefore up to 4 when a qualifying Library candidate exists (3 as before when it doesn't).
- Series/Anime season packs are unaffected: they remain under the existing Best-1 season-pack cap and receive no separate Library reservation.
- SeaDex caps are unchanged.
- Trusted-tier reservation remains out of scope for this release.
- Native Library scoring (StreamNZB's own `+500`) is unchanged and still not duplicated by DraCuLa.

## Compatibility

- StreamNZB: **6.1.0**
- StreamNZB pinned commit: `2ff93449e59a6597f25fd008e3440920772578c3`
- Jhin: **0.7.1**

This baseline is unchanged from 6.2.0.

## Upgrade impact

- A **profile refresh is required** to receive the new Library Best-N reservation.
- No formatter refresh is required solely because of 6.3.0.
- No Define Library refresh is required solely because of 6.3.0.
- The StreamNZB/Jhin compatibility baseline is unchanged.
