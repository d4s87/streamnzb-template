# DraCuLa StreamNZB Template 6.4.6

6.4.6 is a classification patch. SumVision Dolby Vision and HDR10+ Movie releases now receive the existing generated-HDR penalty, `monkee` and `CMRG` join the WEB T2 tiers, and StreamNZB 6.3.0 becomes the validated compatibility baseline.

**Refresh the Define Library after updating to 6.4.6. No Profile or Formatter refresh is required.**

## SumVision generated-HDR correction

SumVision is added to the Movies Generated Dynamic HDR Groups classification.

- SumVision Movie releases with Dolby Vision or HDR10+ receive the existing **-10000** generated-HDR penalty, so they rank below clean releases from the same tier.
- The penalty affects ranking only. It does not reject the release, so a penalized SumVision release is still returned when it is the only result.
- SumVision keeps its Movies Remux T3 classification (**+100**).
- Ordinary HDR10 and SDR SumVision releases are unaffected.

## WEB T2 classification updates

- `monkee` joins **Movies WEB T2**.
- `CMRG` joins **Shows WEB T2**.
- WEB-DL releases from these groups receive the existing **+300** WEB T2 score in the new content kind.
- Their existing classifications in the other content kind are unchanged: `CMRG` stays Movies WEB T1 and `monkee` stays Shows WEB T1.
- As trusted release groups in their new content kind, both groups receive the existing trusted-group exemptions, including those from `Adaptive HD x265`, `Unknown resolution` and `Reject suspicious 4K upscale`.

Rule definitions, tier values and scoring are unchanged. These updates come from the Define Library alone.

## Compatibility

- StreamNZB: **6.3.0**

StreamNZB 6.3.0 is now the validated baseline. Jhin is unchanged. The update does not change DraCuLa's scoring policy, parser behavior or formatter templates. Real-engine compatibility testing against the exact StreamNZB 6.3.0 release passes all 579 compatibility subtests plus the production and debug formatter regressions.
