# DraCuLa StreamNZB Template 6.5.1

6.5.1 is a formatter presentation patch. The result-name star rating now shows filled stars only; empty stars are omitted. Ranking, scoring and result order are unchanged.

**Formatter refresh required. No Profile or Define Library refresh is required.**

## Filled stars only

The stars still rate each result against the best one in the list without StreamNZB's built-in resolution bonus, exactly as in 6.5.0. Only the way the rating is drawn has changed:

| 6.5.0 | 6.5.1 |
| --- | --- |
| ★★★★★ | ★★★★★ |
| ★★★★☆ | ★★★★ |
| ★★★☆☆ | ★★★ |
| ★★☆☆☆ | ★★ |
| ★☆☆☆☆ | ★ |
| ☆☆☆☆☆ | *(no stars)* |

- A result whose rating rounds to zero stars now shows no star segment at all, instead of five empty stars. This includes results with a zero or negative score once the resolution bonus is removed.
- The rating is still calculated by StreamNZB's own star helper, so the number of filled stars for any given result is the same as in 6.5.0.

## What does not change

- Ranking, filtering, scoring, Best-N retention and result order are unchanged.
- The star scale and the score fields behind it are unchanged.
- The numeric score in the description is still the real ranking score.
- The debug formatter, the Profile and the Define Library are unchanged.

## Compatibility

- StreamNZB: **6.4.0** (minimum supported)
- StreamNZB pinned commit: `56fbe4914a08c2fc0960b3fce63c923fc24d8ee7`
- Jhin: **0.8.0**

The compatibility baseline is unchanged from 6.5.0. Real-engine compatibility testing against the pinned StreamNZB 6.4.0 release passes the full compatibility suite plus the production and debug formatter regressions.

## Upgrade impact

**Refresh the Formatter** to receive the filled-star rating.

The **Profile** and **Define Library** are unchanged and do not need to be refreshed. StreamNZB 6.4.0 or newer remains required; if you are already on a supported StreamNZB version, no StreamNZB upgrade is needed.
