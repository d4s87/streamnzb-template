# DraCuLa StreamNZB Template 6.4.5

6.4.5 is a focused scoring-correctness patch for Anime releases. Anime Show and Anime Movie no longer receive size-based scoring, preventing file-size differences from overriding adjacent Anime release-group tiers. Movie and Series size scoring are unchanged.

## Anime tier authority over size scoring

Anime size scoring has been removed from the published profile.

Previously, Anime Show and Anime Movie used bounded size scoring that could contribute up to `+150` and `+500` respectively. Real-engine testing showed that ordinary file-size differences could be enough for a lower Anime release-group tier to outrank the tier directly above it.

- `anime_show` and `anime_movie` are removed from the profile scoring map, so Anime file size now contributes **0 points**.
- Anime release-group tiers therefore retain their intended ordering without a size term overturning adjacent-tier differences.
- Movie size scoring remains **20 GB / +500**.
- Series size scoring remains **6 GB / +150**.
- Anime tier values, BluRay REMUX source authority, Best-N behavior, Library handling, SeaDex behavior, 4K Anime policy, codec/audio scoring, and filtering rules are unchanged.
- The Define Library and formatter are unchanged.

Permanent real-engine regression coverage now checks all adjacent Anime BluRay, BluRay REMUX and WEB tier pairs for both Anime Show and Anime Movie, and verifies that Anime size contributes no score.
