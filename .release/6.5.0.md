# DraCuLa StreamNZB Template 6.5.0

> [!IMPORTANT]
> **StreamNZB 6.4.0 or newer is required. Upgrade StreamNZB before refreshing the DraCuLa formatter.**

6.5.0 raises the minimum supported StreamNZB version to 6.4.0. The formatter's star ratings now ignore StreamNZB's built-in resolution bonus, so a strong lower-resolution release is no longer rated down just because higher-resolution results are in the list. This release also includes a Vidhin GHOSTS classification correction for Movies.

**Upgrade StreamNZB to 6.4.0 or newer first, then refresh the Define Library and the Formatter. No Profile refresh is required.**

## StreamNZB 6.4.0 is now required

DraCuLa's formatter now uses score fields that StreamNZB added in 6.4.0. StreamNZB versions older than 6.4.0 are no longer supported by the current formatter.

On older StreamNZB versions, the formatter still imports without an error, but the result names cannot render. StreamNZB then silently shows its default result names instead of DraCuLa's. If your results lose DraCuLa's formatting after this update, upgrade StreamNZB and refresh the formatter again.

The formatter is still published at the same `formatter.txt` URL. There is no separate formatter for older StreamNZB versions.

## Star ratings without the resolution bonus

StreamNZB adds a large built-in bonus for each resolution step (20,000 points per step, so 2160p carries 40,000 more points than 1080p). Previously the stars included that bonus, so a strong 1080p release rendered only about two stars whenever a 2160p result was in the same list.

The stars now use StreamNZB's resolution-independent score fields, so they rate a release on everything except its resolution. Resolution is still shown separately in the result name.

- A strong lower-resolution release can now receive a high star rating. For example, a dual-audio 1080p BluRay from a top Anime BluRay group can show ★★★★★ below a weaker 2160p WEB release.
- Resolution still counts in StreamNZB's actual ranking. **Result order is unchanged**, as are filtering and Best-N retention.
- The numeric score in the description is still the real ranking score, so it continues to explain why one result ranks above another.
- DraCuLa rules that score resolution, such as the UHD BluRay tiers, still count towards the stars. Only StreamNZB's built-in resolution bonus is removed.
- 720p and releases with no detected resolution receive no built-in bonus, so their stars compare on equal terms.
- If no result in the list has a positive score once the bonus is removed, no stars are shown.

The debug formatter is unchanged.

## GHOSTS classification correction

The Define Library follows Vidhin's latest GHOSTS change, with one local exception.

- **Movies:** `GHOSTS` is no longer classified as a Movies LQ group. It is a Series-only group upstream and in TRaSH. Movie releases from `GHOSTS` no longer receive the **-10000** Movies LQ penalty and are no longer pruned by Adaptive Low-Score Filtering.
- **Series:** behavior is unchanged. `GHOSTS`, `ghosts` and `Ghosts` releases still receive the **-10000** Shows LQ penalty. DraCuLa keeps this match case-insensitive because it compares the parsed release group, so the false positive that led upstream to restrict the match to capital letters cannot occur here.

Rule definitions, tier values and scoring are unchanged. This update comes from the Define Library alone.

## Compatibility

- StreamNZB: **6.4.0** (minimum supported)
- StreamNZB pinned commit: `56fbe4914a08c2fc0960b3fce63c923fc24d8ee7`
- Jhin: **0.8.0**

StreamNZB 6.4.0 is the new validated baseline and minimum. Jhin is unchanged. StreamNZB 6.4.0 does not change parsing, rule evaluation or native scoring. Real-engine compatibility testing against the exact StreamNZB 6.4.0 release passes the full compatibility suite with results identical to 6.3.0, plus the production and debug formatter regressions.

## Upgrade impact

Update in this order:

1. **Upgrade StreamNZB** to 6.4.0 or newer.
2. **Refresh the Define Library** to receive the GHOSTS correction.
3. **Refresh the Formatter** to receive the new star ratings.

The **Profile** is unchanged and does not need to be refreshed.
