# DraCuLa StreamNZB Template 6.4.0

6.4.0 moves the supported compatibility baseline to StreamNZB 6.2.0 / Jhin 0.8.0 and adds seven new non-Anime streaming-service formatter badges: `Movies Anywhere`, `Max`, `Google Play`, `Fandango`, `TVING`, `Viu`, and `iQIYI`. It does not change filtering, scoring, trusted-tier policy, or adaptive filtering.

## Compatibility baseline update

- Supported baseline moves from StreamNZB 6.1.0 / Jhin 0.7.1 to **StreamNZB 6.2.0 / Jhin 0.8.0**.
- This is a compatibility-pin update only — DraCuLa's production rules, formatter, and Define Library content are unaffected by the pin move itself.
- One real-world improvement rides along at no cost: StreamNZB 6.2.0 bundles an updated ffprobe that corrects Dolby Vision Profile 8 detection for already-downloaded Library candidates, so DraCuLa's existing Dolby Vision rules see more accurate input without any rule change.

## Non-Anime streaming-service badges

Seven new streaming services now get a formatter fallback badge on Movie/Series WEB releases when StreamNZB's own `.Network` field doesn't already identify the source: `Movies Anywhere`, `Max`, `Google Play`, `Fandango`, `TVING`, `Viu`, and `iQIYI`.

- `.Network` remains authoritative — a badge only appears when `.Network` is empty, and never duplicates a service `.Network` already shows.
- All seven are presentation-only: zero points, no effect on ranking or scoring.
- Anime titles are unaffected — these badges apply to non-Anime Movie/Series releases only.

**Collision-safety highlights:**

- `Movies Anywhere` recognizes bare `MA` without misfiring on the unrelated `DTS-HD MA` audio-codec tag.
- `Max` recognizes bare `MAX` without misfiring on `HBO Max` branding.
- `Google Play` recognizes `Play` only when it sits directly next to the release's WEB source tag, so it doesn't misfire on ordinary titles that happen to contain the word "Play" (e.g. the *Child's Play* franchise).

`Comedy Central` remains the one non-Anime streaming service without a badge in this release — its only usable release-name signal was judged too collision-prone to add safely.

## Compatibility

- StreamNZB: **6.2.0**

## Upgrade impact

- A **profile refresh is required** to receive the compatibility-pin update and the seven new service badges.
- A **formatter refresh is required** to render the new service badges.
- No Define Library refresh is required — the Define Library is unchanged.
