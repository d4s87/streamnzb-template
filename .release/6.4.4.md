# DraCuLa StreamNZB Template 6.4.4

6.4.4 is a focused correctness and presentation patch with two changes: Anime BluRay remux releases now receive their correct Anime BD tier, and the production formatter's language marker now distinguishes fully probe-confirmed audio languages from everything else. It does not change the StreamNZB/Jhin compatibility pin, Best-N behavior, or the general 1080p-vs-4K resolution ordering.

## Anime BluRay remux tier classification

Anime BluRay tier classification now preserves upstream Vidhin source gating and conditional semantics instead of treating the Anime BD tiers as group-only token lists. The generated `Anime ... BluRay Tn Groups` Defines keep Vidhin's physical-media source gate, each tier's case sensitivity, and its conditional memberships.

- Valid Anime BluRay remuxes, such as those from ZR, PMR and NAN0, now receive the correct Anime BD tier score. Before, they scored like a remux from an unknown group.
- Bare and WEB remuxes from BD-only groups remain untiered.
- The stale LazyRemux/UltraRemux source bypass was removed, so those groups tier only when the release actually carries BD evidence.
- Because the Anime BD Defines are now source-correct, a BD-only group's name no longer makes an unrelated 4K WEB release trusted. This intentionally changes the existing `Trusted Release Groups` and `Reject bad 4K Anime` behavior: such a 4K WEB release is now treated like any other unclassified 4K WEB release.
- The formatter was not changed for this fix. BluRay tier remarks now appear on these remuxes naturally because the correct tier rule matches.
- General 1080p-vs-4K ranking policy is unchanged.

## Source-aware language marker

The production formatter now shows `✓` only when every displayed audio language is confirmed from probed media tracks.

- Partially measured merged language sets, indexer-provided languages, languages inferred from the release name, and subtitle-only lines keep `⛿`.
- This avoids treating `.LanguageSource == "measured"` as proof that every displayed language was measured, since the displayed list can merge measured, indexer-reported and name-inferred languages.
- Subtitle handling, subtitle flags, the 3+N overflow, the debug formatter, scoring and filtering are unchanged.

Both changes are covered by permanent real-engine regression tests against the pinned StreamNZB engine.

## Upgrade impact

All three refreshes are required for 6.4.4, in this order:

1. **Refresh the Define Library first** to receive the source-gated Anime BluRay tier Defines.
2. **Refresh your Profile second** so the Anime BluRay tier rules use the updated Defines.
3. **Refresh the Formatter third** to receive the source-aware language marker.
