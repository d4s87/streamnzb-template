# DraCuLa StreamNZB Template 6.4.2

6.4.2 is a focused scoring-correctness patch: it corrects how much influence file size has on Series and Anime Show ranking, so a smaller SDR release no longer outranks a larger HDR10+/Atmos release of the same release-group tier. It does not change the compatibility baseline, release-group tiers, the production formatter, or the Define Library.

## Series/Anime Show size-scoring fix

DraCuLa bounds the built-in 4K preset's size scoring so file size stays a secondary, streaming-cost preference rather than a dominant ranking factor. A real-world report and a real-engine audit found that Series and Anime Show's prior `+500` maximum (6 GB target, unchanged) let ordinary size differences override deliberate technical preferences: a `Slow Horses` S2E4 2160p WEB-DL search returned a 7.79 GB SDR/DDP5.1 release ranked *above* an 8.69 GB DV+HDR10+/Atmos/DDP5.1 release of the same tier, purely because the smaller file sat closer to the 6 GB target.

Series and Anime Show's size-scoring maximum is now **`+150`** (their 6 GB per-episode target is unchanged). Re-running the same comparison against the real pinned engine, the HDR10+/Atmos candidate now ranks correctly ahead — the scoring delta moves from about `-25` (HDR10+/Atmos losing) to about `+28` (HDR10+/Atmos winning). Size still rewards an efficient, well-targeted encode meaningfully; it no longer overrides a deliberate technical preference over an ordinary size difference.

Movie and Anime Movie are unchanged at their `20 GB` target / `+500` maximum — no evidence supports changing them, and their much larger typical size variance and Edition-class bonuses (e.g. IMAX) already keep size a secondary factor there in practice.

No changes to release-group tiers, HDR/audio preference values, Best-N retention, the formatter, the Define Library, or the StreamNZB/Jhin compatibility pin.
